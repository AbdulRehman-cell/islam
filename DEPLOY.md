# Fast Deployment Guide for Render

Follow these step-by-step instructions to deploy this application to Render in under 5 minutes.

---

## Prerequisites
1. A **GitHub account** containing a copy/fork of this repository.
2. A free **Render account** ([render.com](https://render.com)).
3. A **MongoDB connection string** (e.g., free tier from [MongoDB Atlas](https://www.mongodb.com/cloud/atlas)).

---

## Step 1: Push Repository to GitHub
Ensure all your code changes are committed and pushed to GitHub:
```bash
git add .
git commit -m "chore: setup production deployment files"
git push origin main
```

---

## Step 2: Deploy to Render via Blueprint (Automated)

1. Log in to your **[Render Dashboard](https://dashboard.render.com)**.
2. Click **New +** at the top right and select **Blueprint**.
3. Connect your GitHub repository.
4. Render will detect `render.yaml`. Click **Apply**.
5. During creation, configure required environment variables in Render:
   - `MONGODB_URI`: Paste your MongoDB Atlas string (`mongodb+srv://...`).
   - `CORS_ORIGIN`: Set to your Render URL (e.g., `https://islam-web-service.onrender.com`).
   - `JWT_SECRET`: Auto-generated by Render (or enter custom secret).

---

## Step 3: Setup Automatic CI/CD Pipeline (Optional)

1. In the Render Dashboard, go to your deployed service settings.
2. Copy the **Deploy Hook URL**.
3. Open your GitHub Repository -> **Settings** -> **Secrets and variables** -> **Actions**.
4. Click **New repository secret**.
5. Name: `RENDER_DEPLOY_HOOK_URL`
6. Value: Paste the copied Render Deploy Hook URL.

Every future push to `main` will build, test, and automatically trigger production deployment!

---

## Local Verification Commands

Run locally with Docker Compose to verify app setup before deployment:
```bash
# 1. Copy local environment variables
cp .env.example .env

# 2. Build and start local multi-container environment
docker compose up --build -d

# 3. Check health check status
curl -f http://localhost:10000/health || echo "Ensure Express server handles GET /health route!"
